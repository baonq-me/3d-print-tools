# Repository layout

[← README](../README.md)

Where things go. The full rule set is in [repo-rules.md](repo-rules.md).

| Folder | Holds | Rule |
|---|---|---|
| `converter/` | the STL to 3MF converter | `stl_to_3mf.py` is the command line only; the work is in `converter/src/` |
| `converter/src/` | converter modules | one area per file: `config`, `mesh`, `settings`, `thumbnail`, `package`, `naming`, `inspect`, `slicer`, `gcode` |
| `converter/profiles/` | print profiles | one JSON file per profile, changes on top of the stock presets |
| `converter/template/` | stock preset snapshots | generated by `tools/snapshot_stock_settings.py`, one per material |
| `web/` | local web UI | `app.py` server, `static/` page; third-party code only in `static/vendor/<name>-<version>/` |
| `tools/` | maintenance scripts | run on the workstation, not needed to convert a file |
| `plans/` | plans for new work | static HTML (`plan_<topic>.html`) that renders without JavaScript |
| `docs/` | knowledge | one topic per file, linked from `README.md` |
| `changelog/` | change history | one file per day, `YYYY-MM-DD.md` |
| `samples/` | one sample model and the project made from it | 3DBenchy (CC0); regenerate the `.3mf` when the converter output changes |
| `stl/` | input models | **local only**, git-ignored |
| `gcode/` | sliced G-code | **local only**, git-ignored; made with the Creality Print command line |
| `3mf/` | generated projects | **local only**, git-ignored; rebuild with the converter |

## converter/

```
converter/
  stl_to_3mf.py        command line: arguments, input expansion, output name
  src/config.py        paths, materials, printer limits, plate constants
  src/mesh.py          read STL, weld vertices, watertight check, volume
  src/settings.py      profiles, stock snapshot, custom temperatures
  src/thumbnail.py     point-splat renderer and PNG writer
  src/package.py       plate layout, XML and JSON entries, zip; convert() returns a result
  src/naming.py        default output names, including the variant part
  src/inspect.py       mesh checks: fits, watertight, tilt, bed contact
  src/slicer.py        find and run the Creality Print command line
  src/gcode.py         G-code header, per-layer toolpaths, settings check
  profiles/            quality.json, fast.json, hf_fast.json
  template/            stock_settings_pla.json, stock_settings_petg.json
```

`stl_to_3mf.py` is run as a script, so `converter/` is on the import path and
the modules are imported as `src.<module>`.

## web/

```
web/
  app.py                         FastAPI server on 127.0.0.1 (see docs/web-ui.md)
  static/index.html              the page
  static/app.css                 tokens (dark + light) and components
  static/app.js                  files, settings, convert/slice, 3D view, layer view
  static/vendor/three-0.160.0/   three.js, OrbitControls, STLLoader (MIT, unmodified)
```

`app.py` puts `converter/` on the import path and calls the converter modules
directly.

## Root files

- `README.md` — overview, quick start, doc index.
- `CLAUDE.md` — guidance for AI coding agents.
- `LICENSE` — Apache License 2.0.
- `requirements.txt` — pinned Python packages (numpy; FastAPI, Uvicorn and
  python-multipart for the web UI).
- `.gitignore` — keeps `.venv/`, `stl/`, `3mf/` and archives out of git.
