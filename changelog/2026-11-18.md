# 2026-11-18

## STL to 3MF converter

- `stl_to_3mf.py`: converts a binary or ASCII STL into a Creality Print 7.3
  project for the Ender-3 V3 SE with a 0.4 mm nozzle. The model is centred on
  the bed and never scaled or rotated.
- Settings start from snapshots of the stock presets and a profile is applied
  on top: `quality`, `fast`, `hf_fast` (high-flow nozzle, retraction tuned
  against stringing).
- `tools/snapshot_stock_settings.py` regenerates the snapshots from an
  installed Creality Print and a project saved by it.

## PETG and custom temperatures

- `-m petg` uses the stock `Generic PETG` preset; every profile has its own
  PETG block.
- `--nozzle-temp-first`, `--nozzle-temp` and `--bed-temp` override the
  profile. Values the printer cannot reach are refused; values outside the
  filament preset's range give a warning.
- Generated files go to `3mf/`.

## Several STL files in one project

- Several files or a folder give one project with one plate per STL, laid out
  the way the slicer does it. At most 36 plates per project.
- Single-file output is unchanged.
