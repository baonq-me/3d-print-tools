# 2026-11-22

## Layer height and supports from the command line

- `--layer-height MM` overrides the profile's layer height. Values outside
  the nozzle preset's range (0.08-0.36 mm) are refused.
- `--support` enables the slicer's automatic normal supports; they stay off
  by default.
- Without these options the output is unchanged.
- Docs: usage.md.

## Any slicer setting from the command line

- `--set KEY=VALUE` sets any setting of the stock presets (process, filament
  or machine), for example a brim or the support threshold angle. Repeatable,
  applied after the profile and the other options; unknown keys are refused.
  Values are not range-checked.
- Docs: usage.md.

## Generated projects verified in Creality Print

- Creality Print 7.3.1 has a hidden `--cli` mode that slices a project to
  G-code without the window. A generated project sliced with it: 188 layers
  for a 30.2 mm part at 0.16 mm, bed 65 °C, nozzle 215 °C, as set in the file.
  This is the first check that the slicer applies the embedded settings.
- Docs: project-format.md (new section), usage.md, README, CLAUDE.md. The old
  rule "never start the Creality Print binary" is replaced by "use `--cli`,
  with the window closed".

## gcode/ folder

- Sliced G-code goes to `gcode/` (local only, git-ignored), named after the
  project it was sliced from.
