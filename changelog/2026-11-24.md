## Web UI built

- `web/app.py` (FastAPI, `127.0.0.1` only) and `web/static/` (plain HTML, CSS,
  ES module): add STL files or folders, mesh checks (fits, watertight, tilt,
  bed contact), material/profile/temperatures/layer height/supports/brim and
  any `--set` key, convert, convert & slice with print time, settings check
  and layer preview, 3D view (three.js 0.160.0, copied in), dark and light
  themes, keyboard shortcuts, phone layout.
- Files are saved in `stl/`, `3mf/`, `gcode/`; a file with different contents
  is never replaced without asking (replace, keep both, use the saved one);
  identical files are reused.
- Requests from other hosts and cross-site posts are refused; paths are
  confined to the three folders.
- New converter modules: `naming.py`, `inspect.py`, `slicer.py`, `gcode.py`.
  `convert()` returns a result and has a quiet mode.
- Command line: `--slice` slices with Creality Print into `gcode/` and checks
  the G-code; default names get a variant part for custom layer height,
  supports, tree supports, brim and other `--set` values. Plain runs keep their
  names and packages (checked against the sample, identical apart from dates).
- Checked in headless Chrome: upload, validation, conflict dialog, convert &
  slice (all settings checks pass), layer preview, light theme, 375 px width
  without sideways scrolling, no console errors.
- `requirements.txt`: FastAPI 0.165.0, Uvicorn 0.54.0, python-multipart 0.0.34.
- Docs: new `docs/web-ui.md`; usage.md (`--slice`, variant names),
  repository.md, repo-rules.md, project-format.md, README, CLAUDE.md.
- Fixes found while testing: two slices of the same project differ in the
  slicer's random object ids, so G-code comparison ignores them (and the time
  stamp and UUID); Cancel works even when clicked before the slicing job has
  started; the "Creality Print is open" check matches the executable name only
  (it had matched any command line containing the word) and was tested with a
  stand-in process in both directions; a selection of some files from a folder
  is named `<first>_and_<n>_more`, like the command line, not after the folder.
- Plan items not built: a "Layers" tab in the preview (the layer view is on the
  result screen), and a zip download of 3MF + G-code (separate buttons).

## 3D toolpath view

- The layer preview has a "3D" mode: all extrusion paths up to the slider's
  layer, drawn with three.js (orbit, zoom, pan), top layer in full colour and
  earlier layers darker. It opens showing the whole print.
- Legend entries are buttons that hide a path type in both the 2D and 3D views.
- New endpoint `GET /api/gcode/toolpaths`; responses are gzip-compressed.
- Docs: web-ui.md.
