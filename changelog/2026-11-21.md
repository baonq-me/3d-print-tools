# 2026-11-21

## Repository structure

- Project named `3d-print-tools`.
- The converter moved to `converter/`: `stl_to_3mf.py` keeps only the command
  line, the code is split into `converter/src/` (`config`, `mesh`, `settings`,
  `thumbnail`, `package`), profiles and stock snapshots moved to
  `converter/profiles/` and `converter/template/`.
- Output is unchanged: packages are identical to the ones made before the
  move, apart from the dates.
- New `docs/` (usage, profiles, project format, repository layout, rules) and
  `changelog/`, one file per day. README rewritten as an overview.
- `stl/` and archives are git-ignored, like `3mf/`.

## Snapshot tool works on any OS

- `tools/snapshot_stock_settings.py` no longer has macOS-only paths. It looks
  for Creality Print's presets in the standard per-user and application
  folders on macOS, Windows and Linux and takes the newest version.
- New `--presets-dir DIR` for any other install; searched first, repeatable.
- A preset that is not found now lists the folders that were searched.
- Tested on macOS only: the regenerated PETG snapshot is identical to the
  committed one.

## Projects no longer contain the STL's folder path

- `source_file` in `Metadata/model_settings.config` holds the file name only.
  Before, it held the absolute path, which exposed the local folder layout in
  shared files. Nothing else in the package changed.
