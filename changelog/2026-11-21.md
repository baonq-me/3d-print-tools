# 2026-11-21

## Repository structure

- Project named `3d-print-tools`.
- The converter moved to `converter/`: `stl_to_3mf.py` keeps only the command
  line, the code is split into `converter/src/` (`config`, `mesh`, `settings`,
  `thumbnail`, `package`), profiles and stock snapshots moved to
  `converter/profiles/` and `converter/template/`.
- Output is unchanged: packages are identical to the ones made before the
  move, apart from the dates.
- New `docs/` (usage, profiles, project format, repository layout, rules) and
  `changelog/`, one file per day. README rewritten as an overview.
- `stl/` and archives are git-ignored, like `3mf/`.
